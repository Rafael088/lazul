# Stack: Go, Wails, Kotlin y Next.js

Núcleo en Go (redes, compila para todos los sistemas, gomobile para Android). Escritorio con Wails porque la webview corre MediaPipe Tasks en JS con GPU (MediaPipe no tiene versión para Go). Android en Kotlin nativo, solo receptor en el MVP: Flutter o React Native no aportan con una sola plataforma móvil. Web en Next.js por el panel de Equipos de la fase 4.
